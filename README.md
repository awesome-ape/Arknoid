Arkanoid Game in Java

Description
This is a simple Arkanoid-style game implemented in Java as part of an Object-Oriented Programming course. The game features a ball that bounces around the screen, hitting and breaking blocks. Players control a paddle at the bottom of the screen to keep the ball in play.

Features

Multiple balls in play simultaneously.

Blocks disappear when hit by the ball.

Score tracking.

Paddle control using arrow keys.

Basic collision detection between balls, blocks, and paddle.

Controls

Left Arrow: Move paddle left

Right Arrow: Move paddle right
